# 🎬 Movie Theater Simulation with SimPy

*A discrete-event simulation to optimize staff allocation and reduce customer wait times*

![Simulation Concept Art](https://via.placeholder.com/800x400.png?text=Theater+Simulation+Screenshot) *(consider adding an actual screenshot later)*

## 📖 Overview
This Python simulation models customer flow through a movie theater using SimPy to:
- Analyze bottlenecks in ticket purchasing, food service, and entry processes
- Test staffing configurations before real-world implementation
- Calculate average wait times under different scenarios

**Key Features:**
- 🎟️ Configurable cashier/usher/server counts
- ⏱️ Realistic timing for each service point
- 📊 Automatic wait time calculation
- 🔄 Random customer behavior patterns
